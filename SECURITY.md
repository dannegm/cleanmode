# Security Policy

Clean Mode uses the macOS Accessibility permission to intercept keyboard input, so security and privacy reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it, and the macOS and app versions. You'll get a reply as soon as possible, and we'll agree on a fix and disclosure timeline together.

## What counts

- Anything that makes the app log, store or transmit keystrokes or screen content.
- A way to bypass the lock to run actions it should block, or a way to make the lock impossible to exit.
- Problems in the release or build process (tampered artifacts, unsafe scripts).

## Supported versions

Only the latest release is supported.
